    <div class="dark:text-gray-300 text-body leading-relaxed space-y-4">
                                <p>In investing, there&#039;s an old saying that diversification is the only free lunch  you can reduce risk without necessarily reducing expected return, simply by not putting all your money in one place.</p>
                                            <p>The logic is straightforward: different assets don&#039;t move in perfect sync. When one sector or company is struggling, another may be doing fine, and the gains in one can help offset the losses in another. Spread across enough uncorrelated positions, the swings in your overall portfolio tend to smooth out compared to holding just one or two concentrated bets.</p>
                                            <p>Diversification can happen across several dimensions at once across companies, across sectors, across asset classes like stocks, bonds, and cash, and even across geographies. The goal isn&#039;t to eliminate risk entirely (that&#039;s not possible), but to make sure no single bad outcome can do outsized damage to your plan.</p>
                                            <p>Low-cost, broad-based funds make this easy in practice: a single ETF can offer exposure to hundreds of companies at once, doing in one trade what would otherwise take significant time and research to assemble yourself.</p>

        document.addEventListener('DOMContentLoaded', function () {
            const saved = localStorage.getItem('homeDarkMode');
            const adminDefault = "light" === 'dark';

            if (saved === 'true' || (saved === null && adminDefault)) {
                document.documentElement.classList.add('dark');
            } else {
                document.documentElement.classList.remove('dark');
            }

            updateHomeThemeIcon();
            if (window.lucide) lucide.createIcons();
        });

        function toggleHomeTheme() {
            if (document.documentElement.classList.contains('dark')) {
                document.documentElement.classList.remove('dark');
                localStorage.setItem('homeDarkMode', 'false');
            } else {
                document.documentElement.classList.add('dark');
                localStorage.setItem('homeDarkMode', 'true');
            }
            updateHomeThemeIcon();
        }

        function updateHomeThemeIcon() {
            const isDark = document.documentElement.classList.contains('dark');
            const sunIcon = document.querySelector('#themeToggle [data-lucide="sun"]');
            const moonIcon = document.querySelector('#themeToggle [data-lucide="moon"]');
            if (sunIcon && moonIcon) {
                sunIcon.style.display = isDark ? 'block' : 'none';
                moonIcon.style.display = isDark ? 'none' : 'block';
            }
        }
    </script>
